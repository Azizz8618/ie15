# Электроника 15ИЭ-00-013 — эмулятор терминала

Эмулятор видео-терминала **«Электроника 15ИЭ-00-013»** (Фрязинский дисплей, 1980-е)
на Python. Построен на **настоящих дампах ПЗУ** реального устройства:
знакогенератора КР556РТ5 (`rom/chargen-15ie.bin`) и клавиатуры 15ВВВ-97-006
(`rom/15bbb.rt5`).

Терминал подключается к эмулятору **БЭСМ-6** (SIMH, `~/Yandex.Disk/simh`)
и работает с готовой конфигурацией ОС **Диспак** — `BESM6/OSZAGR/dispak.ini`
(файл и номер telnet-канала не изменяются: эмулятор подстраивается под
имеющийся порт, указанный в `attach ttyN <порт>`).

## Обзор

| Параметр | Значение |
|---|---|
| Экран | 80 знаков в ряду, кадр ЭВМ 25 рядов (как Видеотон-340) и дотягивается до низа окна терминала; служебная панель — под кадром |
| Знакогенератор | 256 глифов 7×8 точек, ПЗУ КР556РТ5 (реальный дамп) |
| Клавиатура | 15ВВВ-97-006 (ёмкостная матрица + ПЗУ `15bbb.rt5`) |
| Кодировка | КОИ7 (ГОСТ 27463-87), 7 разрядов; НАБОРЫ Н0 (ASCII) / Н1 (русские верх+низ) / Н2 (VT-52) — F8, `--nabor` |
| Команды | режим 2 — «набор команд №2» (VT52) по умолчанию; режим 1 — только УП |
| Линия | токовая петля 20 мА → поверх TCP (telnet SIMH) или SSH |
| Режимы | АВТОНОМНО (локальный буфер) / С ЭВМ (обмен с линией) |
| Клавиши | УПР.СИМВ (F7); НАБОР (F8) — Н0 (ASCII) → Н1 (русские верх+низ) → Н2 (VT-52, по умолчанию); СЕТЬ (F9); ПЕРЕДАЧА (F10) |

## Возможности

- Рендер экрана по реальным глифам ПЗУ: ANSI (зелёный люминофор) и PNG.
- Кадр ЭВМ **дотягивается до низа окна**: подвал занимает минимум рядов,
  остальное место окна отдано кадру (у настоящего 15ИЭ — 25 рядов, кадр
  выше только потому, что окно терминала выше). Пустоты под подвалом не
  остаётся ни при каком масштабе шрифта.
- **Строка состояния линии над кадром** (вне кадра ЭВМ — в листание не
  попадает): `КВУ | ЭВМ=6 | ТЕРМ=3 | КАНАЛ=4203 | РЕЖИМ=RAW | 11.10.2026
  02:03:04`. Тип линии и номер терминала — из баннера SIMH, канал — из
  порта, номер ЭВМ — из `[line] machine`. Баннер (`CONNECTED TO …`,
  `ENCODING IS …`, `WRU …`, дата/время) в кадр не печатается; если
  сообщение о подключении не пришло — горит красное «ПРОВЕРЬ ЛИНИЮ!».
  Под ней — черта «-» и одна пустая строка: кадр ЭВМ начинается с
  четвёртого ряда окна.
- Подвал (состояния + легенда клавиш) **растянут на всю ширину окна**
  (не уже 80) ячейками в **ровных колонках**: разделители « | » стоят на
  одних позициях во всех рядах, ячейки не рвутся, ряд состояний отбит
  от легенды чертой «-». Группы справки (F-клавиши, прочая клавиатура,
  сочетания с Ctrl, правка) отличает цвет; группа, целиком влезающая в
  остаток ряда, дописывается в него — свободных колонок подвал не
  оставляет (на 150 знаках — 5 рядов, на 100 — 7, на 80 — 10).
- Цвета подвала: значения состояния — `ВКЛ` зелёный, `ВЫКЛ` красный,
  остальные значения светло-голубые; F-клавиши F5…F10 (верхний ряд
  справки, по порядку) — жёлтые, сочетания с Ctrl — маджента, правка
  (`ДОМ`, `СТЕРСТР`, `ИНВЕРС`, `НОРМ`) — синяя.
- `--no-help` (`[terminal] help = off`) — убрать из подвала ряды-справку
  (легенду клавиш): нижняя строка состояния (поля сеанса, `ПОСЛ:`) остаётся
  в любом случае, освободившиеся ряды достаются кадру ЭВМ.
- `--fit` (`[terminal] fit = on`) — режим «правильного масштаба»: эмулятор
  подгоняет окно ровно на «строка состояния + чёрта с пустой строкой +
  25 рядов кадра + подвал» (`CSI 8 ; высота ; ширина t`), а сбитый
  масштаб шрифта возвращает сам.
- Единая клавиша **НАБОР (F8)** перебирает три режима по ГОСТ 27463-87:
  **Н0** — знаки ASCII (ISO 646 IRV: `¤` `¬` `¯` вместо `$` `^` `~`);
  **Н1** — русские верхний и нижний регистры (КОИ-7 Н1: 0x40…0x5F —
  заглавные «ЮАБЦ…Ч», 0x5F — «Ъ», 0x60…0x7E — строчные) и русская
  раскладка клавиатуры; **Н2** — набор команд №2 (VT-52) с международной
  строкой знаков без замен Н0 (латиница в обоих регистрах, «^» и «$»
  на своих местах; «№» — внутренний знак, на линию идёт позицией 2/3),
  кириллица — только заглавная, кодами ЭВМ — по умолчанию, рабочий режим
  линии БЭСМ-6. Стартовый
  режим — `nabor` в конфиге / `--nabor`, индикатор в подвале;
- Полный разбор «набора команд №2» (частично VT52): курсор, стирание,
  инверсия, позиционирование `ESC Y`, идентификация `ESC Z` и др.
  Нераспознанные управляющие коды (НУС, ЕОТ …) показываются образным
  знаком `код|0x40` с «блинком» — как dim-режим Видеотона-340.
- Два режима работы, как у настоящего терминала:
  - **АВТОНОМНО** (`--mode local`) — набор в локальный буфер с эхом на экран,
    линия свободна (эхо русских букв — заглавные: Н1 не различает регистр,
    так же показывает и ЭВМ);
  - **С ЭВМ** (`--mode host`) — каждый знак немедленно уходит в линию,
    эхо приходит от ЭВМ;
  - клавиша **SEND** (F10) — передать накопленное (незакрытую строку
    завершает ПР ПС), очистить буфер и перейти в режим С ЭВМ.
- Клавиша **НАБОР** (F8) — переключение наборов команд, как на клавиатуре
  15ВВВ: набор 2 (№2, VT52) по умолчанию — с ним терминаль и работает на
  линии БЭСМ-6; в наборе 1 разбираются только управляющие коды.
  В служебной строке (подвале, строки 25+) — панель состояний всех
  управляющих сигналов (`СЕТЬ`, `НАБОР`, `ЛИНИЯ`, `РАСК`, `ЭХО`, `ВИДЕО`,
  `БУФЕР`, `УПР.СИМВ`) и легенда «функция=клавиша» с активаторами F7–F10;
  последняя нажатая клавиша видна в `ПОСЛ:`. Панель растянута на всю
  ширину окна (не уже 80) и занимает минимум рядов — на 80 знаках 6 рядов.
  Переключение сеанса АВТОНОМНО ↔ С ЭВМ — F9, показ знаков УП — F7
  (см. `docs/COMMANDS.md`).
- КОИ7 Н1 в обе стороны: русские буквы кодируются/декодируются по таблице
  `ЮАБЦДЕФГХИЙКЛМНОПЯРСТУЖВЬЫЗШЭЩЧ`. Внутри эмулятора заглавные несут
  «бит алфавита» (0x80), поэтому «М» не сливается с возвратом каретки;
  на линию они сворачиваются в зависимости от её кодировки (см. ниже).
- Линии: `tcp://` (прямое подключение к telnet-линии SIMH), `ssh://` (через
  `besm6/ssh_bridge.py`), `stdio://` (отладка без сети).
- Кодировка линии определяется по баннеру SIMH (`Encoding is UTF-8`,
  `RAW`/`RAW8`, `KOI-7 …`, `Connected to DKS`) и подстраивается под приём
  и передачу:
  UTF-8-кириллица от ЭВМ декодируется в КОИ7, обратно русские буквы уходят
  либо как UTF-8, либо как внутренние 7-разрядные коды (строка 0x60…0x7E);
  telnet-IAC вырезается stateful в `link.py`, обрыв UTF-8 на границе `recv`
  дозаполняется из следующего чтения.

## Быстрый старт

Требуется Python 3.10+. Сторонние зависимости — только `paramiko` для SSH-линии
(для `tcp://` и `stdio://` ничего не нужно).

```bash
cd ~/Yandex.Disk/ie15

# 1. Проверка без сети (демо-скрипт + PNG)
python3 -m ie15emu --script demo --png shots/demo.png

# 2. Запуск БЭСМ-6 с готовым dispak.ini (отдельная tmux-сессия, файл не меняем)
tmux new-session -d -s besm6 -c
~/Yandex.Disk/simh/BESM6/OSZAGR/dispak.ini

# 3. Подключение терминала к telnet-линии (порт как в dispak.ini,
#    см. строку 'attach ttyN <порт>')
python3 -m ie15emu --line tcp://127.0.0.1:4202 --png shots/besm6.png

# 4. То же через SSH-мост (вторая tmux-сессия); цель можно задать
#    диапазоном — мост сам выбирает первую свободную линию Э-60
python3 besm6/ssh_bridge.py --hostkey besm6/host_ed25519_key \
        --port 2222 --target 127.0.0.1:4199-4223
python3 -m ie15emu --line ssh://ie15@127.0.0.1:2222 --password ie15

# 5. Прямой TCP с перебором диапазона (занятые линии пропускаются)
python3 -m ie15emu --line tcp://127.0.0.1:4202 --port 4202-4223
```

## Установка (ярлык на рабочем столе)

**Linux** — ярлык в меню приложений и на рабочий стол; двойной щелчок
открывает окно терминала с интерактивным сеансом (длится до Ctrl-C):

```bash
cd ~/Yandex.Disk/ie15 && ./install.sh
```

**Windows** — Python 3.10+ (для `ssh://` ещё `pip install paramiko`), затем:

```bat
powershell -ExecutionPolicy Bypass -File install.ps1
```

Ярлык «Электроника 15ИЭ (терминал)» запускает `ie15.cmd` в окне консоли.

## Конфигурация (ie15.conf)

Файл `ie15.conf` в корне проекта задаёт подключение по умолчанию
(аргументы командной строки перекрывают его):

| Секция/параметр | Назначение |
|---|---|
| `[line] type` | `ssh` (через мост) или `tcp` (telnet-линия SIMH напрямую) |
| `[line] server` | адрес сервера с БЭСМ-6 / SSH-мостом |
| `[line] port` | номер канала — telnet-порт линии SIMH (`attach ttyN <порт>`); можно список (`4202,4210`) или диапазон (`4202-4223`): берётся первая свободная линия, занятые пропускаются |
| `[line] ssh_port` | порт SSH (22 — sshd сервера; 2222 — мост `ssh_bridge.py`), тоже список/диапазон |
| `[line] machine` | номер ЭВМ для строки состояния над кадром (пусто — не показывается) |
| `[ssh] user` | пользователь SSH (по умолчанию `test@besm6.cs.msu.ru`) |
| `[ssh] keyfile` | файл закрытого ключа ssh по умолчанию (`~/.ssh/besm_test`; `~` раскрывается; если файла нет — используется пароль) |
| `[ssh] password` | пароль (когда ключ не задан/не найден) |
| `[terminal] mode` | `host` (С ЭВМ) или `local` (АВТОНОМНО) |
| `[terminal] sets` | набор команд при запуске: `2` (VT52) или `1` |
| `[terminal] history` | строк «истории» выдачи над экраном для PgUp/PgDn (по умолчанию `1000`; `0` — не сохранять) |
| `[terminal] nabor` | НАБОР: `n0` — ASCII, `n1` — русские верх+низ (КОИ-7 Н1) с русской раскладкой, `n2` — VT-52 (по умолчанию); он же `--nabor`, переключается F8; устаревшие `sets`/`charset` уступают ему |
| `[terminal] layout` | русская раскладка: `positional` — по положению клавиш ЙЦУКЕН (по умолчанию: q→Й), `phonetic` — фонетическая (q→Я, w→В), `off` — выключена |
| `[terminal] koi7` | `true` — включить раскладку (`layout` по умолчанию — позиционную), если `layout` не задан |
| `[terminal] mouse` | `false`/`off` — мышь остаётся терминалу (колесо листает экран самого терминала); по умолчанию мышь отдана эмулятору: колесо листает «историю» выдачи по три ряда, циклической прокрутки нет |
| `[terminal] fit` | `true`/`on` — подгонять окно терминала ровно на «25 рядов кадра + подвал» (`CSI 8;h;w t`, сбой масштаба возвращается при приходе символа от ЭВМ); по умолчанию окно не трогается — кадр ЭВМ сам дотягивается до низа окна |
| `[terminal] help` | `false`/`off` — убрать из подвала ряды-справку (легенду клавиш); нижняя строка состояния остаётся в любом случае, освободившиеся ряды достаются кадру (то же — `--no-help`) |
| `[keys]` | переназначение клавиш: `что_пришло = что_набирать` — знак, строка, `KEY-имя` или код УП `\xNN` (Ctrl+клавиша); пустое значение гасит клавишу. Применяется до правил набора. Код нажатого УП видно в подвале (`ПОСЛ: УП NN`) — по нему и правят привязку. Если терминал понимает CSI-u (kitty, foot, wezterm, alacritty; xterm: `-modifyOtherKeys 2 -formatOtherKeys 1`; VTE — нет), эмулятор при запуске сам включает протокол, и тогда ключом служит само нажатие с модификатором — `ctrl+Б = <`, `alt+Х = …` — без дублей с обычными знаками; имя незакрытого сочетания тоже показывает подвал. Без CSI-u Alt читается как ESC-префикс и именуется так же (`alt+б`); если Ctrl+кириллица приходит обычным знаком (модификатор потерян) — подвал это и покажет, отличить клавишу нельзя, привяжите другой модификатор. В подвале (`ПОСЛ:`) видно каждое нажатие: знак с кодом (`б U+0431`), УП (`УП 1C`), имя с модификатором и итог переназначения (`ctrl+б→< U+003C`). В комплекте привязаны (именами и кодами, Ctrl и Alt) `ctrl/alt+Б=<`, `ctrl/alt+Ю=>`, `ctrl/alt+Х=[`, `ctrl/alt+Ъ=]`, `ctrl/alt+6=^` (`shift+?` даёт `|` и проходит без привязки) |

Другой файл: `./ie15 --conf /путь/ie15.conf`.

### Диалоговый режим (интерактивный сеанс)

Для живого диалога служит лаунчер `./ie15` — он, в отличие от прямого
`python3 -m ie15emu`, по умолчанию ведёт сеанс до `Ctrl-C`
(в CLI-режиме без `--seconds` выход через 30 с) и требует реального
терминала (xterm, putty, tmux; раскладка любая, нужен UTF-8).
Запуск **без аргументов** (в т.ч. двойным щелчком в файловом менеджере) —
диалог с сервером по умолчанию из `ie15.conf`: `ssh://test@besm6.cs.msu.ru`
(ключ `~/.ssh/besm_test`), линии `4202-4223` с автоматическим перебором;
после завершения окно ждёт Enter,
чтобы пользователь успел прочитать результат или ошибку:

```bash
./ie15                                              # по умолчанию: ssh://test@besm6.cs.msu.ru
./ie15 --line tcp://127.0.0.1:4202               # С ЭВМ: клавиши в линию, эхо от машины
./ie15 --line ssh://ie15@127.0.0.1:2222 --password ie15   # тот же диалог через SSH-мост
./ie15 --line tcp://127.0.0.1:4202 --mode local  # АВТОНОМНО: набор в буфер, F10 — SEND
./ie15 --port 4202-4223                          # перебор диапазона: занятая линия
                                                 # («Line connection busy» от ЭВМ)
                                                 # пропускается, подключаются к следующей
```

Порт (`--port` и `port` в конфиге) можно задать одним числом, списком
(`4202,4210`) или диапазоном (`4202-4223`): терминал идёт по портам по
порядку, занятые и недоступные пропускает; если свободных не осталось —
сообщает «нет свободной линии» со списком занятых/недоступных. У SSH-моста
то же: `--target 127.0.0.1:4199-4223` выбирает первую свободную линию
Э-60 на каждой сессии, так что одна команда подключения обслуживает все
23 линии сразу.

Несколько копий одновременно: сервер ДИСПАК поднят на 23 линии Э-60
(терминалы 2–24), порт линии N — `4199+N` (4202…4223), а 4199 — игровая
линия «ИГРА» (шифр 4199). Одна линия — одна копия (токовая петля не
мультилексируется). **Больше не нужно расписывать порты руками**: по
умолчанию (в `ie15.conf`, в лаунчерах `./ie15` и `ie15.cmd` и у
SSH-моста) стоит диапазон `4202-4223` — каждая следующая копия сама
проходит по занятым линиям и берёт первую свободную; если свободных нет,
терминал сообщает «нет свободной линии» со списком занятых/недоступных.
Явный выбор — `--port` (число, список или диапазон) или `--line
tcp://host:диапазон`. После преждевременного выхода копии слот Э-60
освобождает ОС, переподключение может подождать несколько секунд (тесты
переподключаются сами).

Порядок в ДИСПАК: подсказка `Type HYC<enter>` — набрать `HYC` и Enter
(эхо у линии по умолчанию выключено), дождаться «ЗДРАВСТВУЙТЕ! ОС ДИСПАК…»,
затем приказы (`ВЫД`, `ЗАД`, `ГОД`, …); приглашение «ЭВМ-3,TNNN» — на пустую
строку Enter. Служебная строка внизу показывает режим; обрыв линии
завершает сеанс сообщением, а не падением.

### Клавиши терминала (в сеансе)

| Клавиша ПК | Действие |
|---|---|
| обычные знаки | ввод в линию (С ЭВМ) или в буфер (АВТОНОМНО) |
| Enter / Tab / Ctrl-G | ПР ПС (`0D 0A`) / ТАБ (`09`) / ЗВН (`07`) |
| Backspace | ВК (`08`, «authbs») |
| Стрелки / Home / End | `ESC A/B/C/D`, `ESC H`, `ESC K` (набор команд №2) |
| PgUp / PgDn | листание «истории» выдачи и экрана вверх/вниз (до первой и последней выданной строки, без циклического показа пустоты); вверх — только когда выдано больше одной страницы кадра; в линию не уходит |
| колесо мыши | то же листание «истории» по три ряда за щелчок (мышь терминала отдана эмулятору, `mouse = off` в конфиге — возвращает её терминалу); вверх — как PgUp, без циклической прокрутки |
| Ins / Del | `ESC b` / `ESC c` (инверсное / нормальное видео) |
| Ctrl+← / Ctrl+→ | курсор на начало текущего / следующего слова (разделители — пробел и точка) |
| Ctrl+↑ / Ctrl+↓ | курсор в начало текущей / нижней строки |
| **F6** | **ЭХО** — подавить вывод набора на экран (для паролей): клавиши уходят в линию, но не печатаются; эхо-ответ линии срезается до повторного нажатия |
| **F5** | **ОЧИСТКА** — очистить экран (кадр ЭВМ) с возвратом в начало; сошедший экран уходит в «историю», история не стирается. Видимая страница всегда стирается: кадр занимает верх окна, «запаса» рядов, куда выползала бы история, нет |
| **F6** | **ЭХО** — подавить вывод набора на экран (пароли): клавиши уходят в линию, но не печатаются; эхо-ответ линии срезается до повторного нажатия |
| **F7** | **УПР.СИМВ** — показывать/скрывать образные знаки управляющих символов (режим blink ВТ-340); по умолчанию выключен |
| **F8** | **НАБОР** — Н0 ↔ Н1 ↔ Н2 (VT52) |
| **F9** | **СЕТЬ** — АВТОНОМНО ↔ С ЭВМ |
| **F10** | **ПЕРЕДАЧА (SEND)** — отдать буфер в линию, очистить его и перейти в С ЭВМ |
| Ctrl-C | выход |

(F1 и F11 не используются — перехватываются окружением рабочего стола)

#### Н2: раскладка не нужна — алфавит выбирает CapsLock

В Н2 терминаль одно-регистрный (так же отвечает ЭВМ), поэтому реальную
раскладку клавиатуры переключать не нужно:

| Что нажато | Латинская раскладка ОС | Русская раскладка ОС |
|---|---|---|
| буква без Shift/Caps | английские заглавные | русские заглавные |
| буква с Shift (или любой буквой включённый **CapsLock**) | русская буква того же положения ЙЦУКЕН (W→Ц) | английская буква того же положения (Ц→W) |

Знаки `^ @ # № [ ] ' | ? % ; ! > <` набираются одним и тем же знаком с
обеих раскладок и при любом положении CapsLock (карта построена по
самому знаку): на латинской раскладке — обычные клавиши (№ — AltGr),
на русской — общая физическая клавиша: `"` (Shift+2)→`@`, `:` (Shift+6)
→`^`, `№` (клавиша 3)→номерной знак `№` (на линию — позиция 2/3),
`ё/Ё` (клавиша `|`)→`|`, `ъ/Ъ` (клавиша `]`)→`]`; `'` и `[` —
Shift+`э`/Shift+`х` (те же клавиши, где на латинской раскладке `'` и
`[`); `# ? % ; !` на русской раскладке — те же Shift+3/7/5/4/1, что и
на латинской. `«`/`»` и неразмеченные клавиши в Н2 не переводятся; чего
не хватает на русской раскладке (`<`, `>`) — добирается Ctrl-сочетаниями,
привязанными в секции `[keys]` конфига.

### Кодировка КОИ7 Н1

Русские буквы кодируются по 7-разрядной таблице (ГОСТ 27463-87):

| Диапазон кодов | Содержимое |
|---|---|
| `0x00…0x1E` | заглавные русские (Н1): Ю А Б Ц Д Е Ф Г Х И Й К Л М Н О П Я Р С Т У Ж В Ь Ы З Ш Э Щ Ч |
| `0x20…0x5F` | цифры, знаки, заглавные латинские |
| `0x60…0x7E` | строчные русские (тот же порядок, код `\| 0x60`) / `0xE0…0xFE` — они же с битом алфавита |
| `0x7F` | сплошная заливка (непрозрачный блок) |

Заглавные Н1 (`0x00…0x1E`) сталкиваются с управляющими кодами («М»=`0x0D`
= ПР), поэтому во внутреннем потоке (парсер, буфер SEND) русские буквы
несут **бит алфавита** 0x80: заглавная = `0x80…0x9E`, строчная = `0xE0…0xFE`.
В ОЗУ кадра после `put()` остаётся 7-разрядный код ВЗУ.

Линии SIMH БЭСМ-6 говорят в трёх кодировках; режим ПЕРЕДАЧИ выбирается по
баннеру при подключении (`Encoding is …`), приём определяется по самому
потоку (`ie15emu/charset.py`):

| Линия (команда SIMH) | ЭВМ → терминал | терминал → ЭВМ |
|---|---|---|
| `set ttyN unicode` (по умолчанию) | UTF-8 | UTF-8 (`unicode_to_koi7` в SIMH кладёт букву в строку `0x60…`) |
| `set ttyN raw` / `raw8` | внутренние коды БЭСМ-6 | те же коды: буква — строка `0x60…0x7E`, конец строки — ETX |
| `set ttyN jcuken` / `qwerty` | UTF-8 | та же строка `0x60…0x7E` (живой эталон: «ВЫД» → `wyd`) |
| `set ttyN dks,raw` (линия Э-60) | внутренние коды БЭСМ-6 (НУСов нет; подтверждение ОС — «NNNN) ») | те же коды, окончание строки — ПР (Э-60 читает ПР/ПС, не ETX) |

Функции тракта: `encode_koi7()` (Unicode → КОИ7 с битом алфавита),
`decode_koi7()` (ОЗУ кадра → Unicode), `normalize_line_bytes()` /
`normalize_incremental()` (поток ЭВМ → парсер, с дозаполнением разорванного
UTF-8), `to_line()` (внутренний поток → байты линии). Telnet-IAC вырезается
stateful в `link.py` (`IacStripper`), ESC Z получает ответ `ESC /` в линию.
Поэтому обмен с БЭСМ-6 идёт русскими буквами в обе стороны без искажений.

## Запуск тестов

```bash
# юнит-тесты (без сети):
python3 tests/test_charset.py
python3 tests/test_keyboard.py
python3 tests/test_parser.py
python3 tests/test_session.py
# или всё сразу:
for t in tests/test_*.py; do python3 "$t"; done
```

Живые тесты (требуют запущенного `besm6` с линией на 4202; без него
скипаются): `test_besm6_live.py` — протокол линии по сырому socket,
`test_line_roundtrip.py` — весь эмулятор через TCP и через SSH-мост,
включая АВТОНОМНО с клавишей SEND. Работают с линией и в `raw`, и в
`unicode` (кодировка определяется по баннеру).
