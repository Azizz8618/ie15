# Набор команд №2 (совместимость с VT52)

Терминал «Электроника 15ИЭ-00-013» разбирает поток от ЭВМ построчно,
побайтово. Управляющие коды УП (0x00…0x1F) и ESC-последовательности образуют
«набор команд №2», частично совместимый с DEC VT52.

## Режимы (клавиша «НАБОР», F8; запуск — `--sets 1|2`)

- **Режим 2** (по умолчанию, набор №2 / VT52): разбираются и УП, и
  ESC-последовательности ниже. С БЭСМ-6 терминаль работает в режиме 2.
- **Режим 1** (набор №1): только УП и печать; ESC гасится, следующий за ним
  знак — обычная печать (команд-параметров нет).

Текущий режим горит в подвале («НАБОР=1(УП)» / «НАБОР=2(VT52)»).

## Служебная строка (подвал, строки 25+)

Панель из нескольких рядов (каждый ≤80 знаков): три ряда состояний всех
управляющих сигналов (в третьем — подсветка последней нажатой клавиши),
отделительная черта и ряды-легенды «функция=клавиша_ПК». Все ряды — по
четыре колонки равной ширины, разделители « | » на одних позициях:

```
СЕТЬ=С ЭВМ        | НАБОР=2(VT52)     | ЛИНИЯ=ДКС         | РАСК=ПОЗ
ЭХО=ВКЛ           | ВИДЕО=НОРМ        | БУФЕР=ПУСТО       | УПР.СИМВ=ВЫКЛ
ПОСЛ: END=ESCK  | ЗНАКИ=Н0
--------------------------------------------------------------------------------
ВК=Bksp           | ТАБ=Tab           | ЗВН=Ctrl-G        | ПРПС=Enter
ESC=Esc           | КУРСОР=Стрелки    | ДОМ=Home          | СТЕРСТР=End
СЛОВО=Ctrl+→      | СЛОВО=Ctrl+←      | НАЧСТР=Ctrl+↑     | НИЖСТР=Ctrl+↓
ЭКРАН↑=PgUp       | ЭКРАН↓=PgDn       | ИНВЕРС=Ins        | НОРМ=Del
ЭХО=F6            | УПР.СИМВ=F7       | НАБОР=F8          | СЕТЬ=F9
ПЕРЕДАЧА=F10      | ОЧИСТКА=F5
```

Ряды состояний отделены чертой от рядов-легенд; все колонки равной
ширины (4 × 17 знаков), разделители « | » стоят на одних позициях.

| Поле ряда состояний | Значения |
|---|---|
| `СЕТЬ=` | `С ЭВМ` / `АВТОНОМНО` (F9) |
| `НАБОР=` | `2(VT52)` / `1(УП)` (F8) |
| `ЛИНИЯ=` | тип линии по баннеру SIMH: `UTF-8`, `RAW`, `ДКС` |
| `РАСК=` | `ПОЗ` / `ФОН` (позиционная/фонетическая) или `ВЫКЛ` |
| `ВИДЕО=` | `НОРМ` / `ИНВ` (Ins / Del) |
| `БУФЕР=` | число знаков, ждущих ПЕРЕДАЧИ (F10), либо `ПУСТО` |
| `УПР.СИМВ=` | `ВКЛ` — нераспознанные УП печатаются образными знаками с миганием, `ВЫКЛ` — скрыты (F7, по умолчанию выключен) |
| `ЭХО=` | `ВКЛ` — набор виден на экран; `ВЫКЛ` — клавиши уходят в линию, но не печатаются и эхо-ответ линии срезается (защита паролей) (F6) |

## Наборы знаков (КОИ-7, ГОСТ 27463-87)

Терминал знает два набора отображения кодов ВЗУ (ключ реестра
`[terminal] charset`, CLI `--charset`):

| Набор | 0x20…0x3F | 0x40…0x5F | 0x60…0x7E |
|---|---|---|---|
| **Н0** (международный, ISO 646 IRV; по умолчанию) | цифры, `¤`(0x24), `¬`(0x5E), латиница заглавная | `@`…`_` (латинская строка) | `a`…`z` строчная; в традиции ЭВМ здесь русские строчные (см. ниже) |
| **Н1** (первый национальный) | тот же (цифры/знаки общие) | **Ю А Б Ц Д Е Ф Г Х И Й К Л М Н О П Я Р С Т У Ж В Ь Ы З Ш Э Щ Ч** (0x40…0x5E), `Ъ` (0x5F) | те же буквы **строчными** (ю а б ц … ч) |

Строчная строка 0x60…0x7E трактуется как русская строчная в обоих
наборах — так ЭВМ отдаёт Н1 (одно-регистные строки кодов в играх
«ИГРА»/«КАЛАХ»), и так же работает приём raw-линии SIMH
(`koi7_raw_upper`). Текущий набор виден в подвале (`ЗНАКИ=Н0/Н1`).

## Управляющие коды (УП)

| Код | Сокр. | Действие |
|---|---|---|
| `0x07` | ЗВН | звонок (звонок терминала) |
| `0x08` | ВК  | курсор влево |
| `0x09` | ТАБ | табуляция (шаг 8 позиций) |
| `0x0A` | ПС  | новая строка (перевод с возвратом каретки — драйвер ДИСПАК печатает Электронике строки шаблоном «ПС текст ПР») |
| `0x00` | NUL | пустой код: не печатается и каретки не двигает (кадры ВТ-340 идут парами «ПС NUL NUL», сдвиг на нём ломал раскладку кадра КАЛАХА). Не путать с приказом ДИАЛОГа «НУС» — подключение нового терминала (холодный старт) |
| `0x0B` | ПП  | пустая операция (как у DEC-терминалов и Видеотона-340) |
| `0x0C` | ПФ  | «дом» (0,0) — без стирания (как `\f`→`ESC[H` у Видеотона) |
| `0x0D` | ПР  | возврат каретки |
| `0x1B` | ESC | ввод ESC-последовательности |

## Одно-байтовые команды Видеотона-340

Программы ДИСПАК (например «ИГРА 4199») рисуют поле кодами Видеотона
(`besm6_tty.c`, `vt_send`); терминал принимает их в дополнение к набору
№2 — в самом наборе №2 эти коды свободны (русские буквы ЭВМ шлёт
строкой `0x60..`, а не кодами `0x00..0x1E`):

Операторский терминал ДИСПАК видит ровно те же коды: `vt_send`
превращает их в ANSI (`0x19→ESC[A`, `0x1A→ESC[B`, `0x18→ESC[C`,
`0x0C→ESC[H`, `0x1F→ESC[H ESC[J`, `0x0B` передаётся как есть), поэтому
курсорные команды Видеотона **ничего не стирают** — служебные строки
игры вписываются поверх свободных рядов под полем:

| Код | Видеотон | Действие 15ИЭ |
|---|---|---|
| `0x08` | влево | ВК (курсор влево) — уже был |
| `0x0B` | — | пустая операция (сдвиг курсора `\v` уводил бы кадр хода за экран) |
| `0x0C` | дом | курсор в «дом» (0,0), без стирания |
| `0x18` | вправо | курсор вправо |
| `0x19` | вверх | курсор вверх |
| `0x1A` | вниз | курсор вниз (без стирания) |
| `0x1F` | стирание экрана | стирание + курсор в «дом» |

## Прочие управляющие коды

Коды `0x00…0x1E` вне таблиц выше (ЕОТ, СО …) не имеют действия в
наборе команд №2 и печатаются **образным знаком `код|0x40` с «блинком»**
(клавиша УПР.СИМВ, F7; по умолчанию скрыты) — как dim-режим
Видеотона-340: ЕОТ → `C`. NUL (`0x00`) — исключение: не печатается
и каретки не двигает.
Заглавные русские буквы КОИ7 Н1
(ГОСТ 27463-87) приходят только в форме бита алфавита `0x80+i`
(её расставляют `normalize_line_bytes`/`koi7_raw_upper` и клавиатура);
строчные — кодами `0x60…0x7E`.

## ESC-последовательности

| Последовательность | Действие |
|---|---|
| `ESC A` | курсор вверх |
| `ESC B` | курсор вниз |
| `ESC C` | курсор вправо |
| `ESC D` | курсор влево |
| `ESC H` | курсор в «дом» (0,0) |
| `ESC I` | курсор вверх со скроллом вниз (RI) |
| `ESC J` | стирание до конца экрана: текущая строка от курсора и все нижележащие |
| `ESC K` | стирание до конца строки |
| `ESC Y r c` | курсор в позицию `(r+20h, c+20h)` — VT52 Direct Cursor Address |
| `ESC E` | очистка всего экрана целиком, курсор в «дом» (0,0) |
| `ESC b` | инверсный видео |
| `ESC c` | нормальный видео |
| `ESC Z` | идентификация терминала (ответ `ESC /`) |
| `ESC ESC` | сброс |

## Соответствие клавиш ПК → коды линии

| Клавиша | Коды |
|---|---|
| Enter | `0D 0A` (ПР ПС) |
| Backspace | `08` (ВК, «authbs») |
| Tab | `09` (ТАБ) |
| Ctrl-G | `07` (ЗВН) |
| Esc | `1B` (начало ESC-последовательности) |
| Стрелки ↑ ↓ → ← | `ESC A` / `ESC B` / `ESC C` / `ESC D` |
| Home | `ESC H` |
| End | `ESC K` (стереть до конца строки) |
| PgUp / PgDn | `ESC J` / `ESC E` (стереть до конца экрана / очистить) |
| Insert / Delete | `ESC b` / `ESC c` (инверсное / нормальное видео) |
| Ctrl+→ | курсор на начало следующего слова (разделители — пробел и точка; локально, в линию не уходит) |
| Ctrl+← | курсор на начало текущего слова; если уже там — на начало предыдущего |
| Ctrl+↑ | курсор в начало текущей строки |
| Ctrl+↓ | курсор в начало строки ниже |
| F5 | ОЧИСТКА — очистить экран (кадр ЭВМ) с возвратом в начало первой строки; сошедший экран сохраняется в «истории» (листается PgUp/PgDn), история не стирается (служебная) |
| F6 | ЭХО — подавить вывод набираемого на экран (клавиши уходят в линию, эхо-ответ линии срезается до повторного нажатия; для паролей) (служебная) |
| F7 | УПР.СИМВ — показывать/скрывать образные знаки нераспознанных УП (как режим blink Видеотона-340); по умолчанию выключен (служебная) |
| F8 | НАБОР — набор команд №1 ↔ №2 (VT52), как клавиша на 15ВВВ (служебная) |
| F9 | СЕТЬ — АВТОНОМНО ↔ С ЭВМ (служебная) |
| F10 | ПЕРЕДАЧА (SEND) — отдать буфер в линию (незакрытую строку завершает ПР ПС), очистить буфер и перевести сеанс в С ЭВМ |

Клавиши F1 и F11 не используются: их перехватывает окружение рабочего
стола; F12 эмулятором не обрабатывается.
